# AE聚合核心

<BlockImage id="applied_more_machines:ae_crafting_core" scale="6" />

AE聚合核心读取实际加载的龙之研究聚合配方，遵守数据包修改。
保留原配方的中心主材料、数量、注入器等级、FE 耗能，以及能保留工具／模块数据的原始产物生成逻辑。
使用时请给样板供应器开启阻挡模式。
遇到大粪NBT配方（点名通量容器），请使用闪电科技的过载供应器上过载样板，忽略NBT。

## 使用

1. 在**中间上方**安装聚合注入器。每个注入器解锁左右两侧的一格材料槽，同一堆只能放同等级注入器，最多 **16 个**，加工不消耗。
2. 在**中间下方**放入配方中心主材料，其余材料放在已解锁的两侧槽位，摆放顺序不限。
3. 连接可用的 ME 网络，或从任意面接入 FE。共用缓冲初始为空，最大存储 **256,000,000 AE**。
4. 完成后，中间下方的主材料**原位替换为成品**，先取出成品，再开始下一次配方。

## 注入器等级与槽位

注入器等级从低到高为：**基础、飞龙、神龙、混沌**。高级兼容低级，但不能用低等级设备制作高等级配方。
注入器数量只决定可用材料格数，同种可堆叠材料允许共用一格。
机器仍完整核对已解锁槽位内的材料、数量与组件；不可堆叠的材料需要分别占格。

开始付出能量或推进进度后，包括缺电暂停时，注入器都不能取出或替换。
空闲时减少注入器，失去解锁的格子内材料会退回操作玩家的背包；背包装不下则取消本次取出，不会吞物。

中心主材料和两侧材料均可按物品原生上限堆叠。材料符合配方且数量足够即可加工，每次仅扣除一份配方所需数量，多余材料保留。完成时中心槽仍放成品，多余的中心主材料退回已解锁的材料槽；没有足够空间时暂停，不扣料、不丢失余料。

## 升级卡

右侧四个卡槽每格一张，支持 AE2 加速卡和水晶科技的陨石超频卡，允许混装，总数最多四张。
基础耗时160tick，一张加速卡减少20tick，一张陨石超频卡减少40tick，最小配方完成时间为1tick

## 倍增卡

安装数据能源后，在原有升级槽外增加一个单张倍增卡专槽。产量取整、并行、返还物及ME余量规则见[倍增卡](multiplication_card.md)。
