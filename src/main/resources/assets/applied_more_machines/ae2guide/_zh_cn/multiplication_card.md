# 倍增卡

同时安装数据能源时，本模组原本有升级槽的加工机器会增加一个 `data_energistics:multiplication_card` 专用槽，最多放一张。通用工厂和AE反应堆的两个控制器整座共用一次效果；成型前分别装卡也不会叠加。附魔台保持原有行为。

每份原生配方的正式产物增加 **50%，先向上取整，再乘实际并行份数**。例如原配方1→1变为1→2，并行八份得到16个；原生每份产出3个则变为5个。物品、流体、化学品和副产物均适用，空桶等容器返还物保持原量。炼药机每批原生三瓶变为五瓶；免费玻璃瓶装水仍为三瓶。

耗材、并行上限、加工时间和能耗沿用原规则。加工样板仍填写**一份原生配方的数量**，不要把倍增后的产量写进样板；加成不会增加向CPU请求的材料。

产物优先放入相容的本地产物槽或储罐，全部装不下的余量（包括原本产量）直接送入ME存储，不受相邻自动输出开关和方向配置限制。ME断线、满仓或只收一部分时，剩余产物保存并暂停后续加工，直到安全交付。取出卡片不会丢弃已经生成的余量。

压印器x8/x64保留512/1024的产物槽容量，所有实际并行份数都获得加成。旧普通升级槽中的倍增卡会在机器下次tick时迁入专槽。可通过专槽、背包Shift转移或手持卡潜行右键安装。
