# AE流体镭射钻

<BlockImage id="applied_more_machines:ae_fluid_laser_base" scale="6" />

需要安装工业先锋与工业先锋：更多升级（ifeu） ，缺少时，本机器不注册。
读取当前世界已加载的紫色、幽匿、龙镭射聚焦透镜的流体钻取配方，结构催化剂代替原配方的实体，不要求群系维度或高度。

## 产量与限速

基础每轮8秒，整轮共耗4,000 AE，产量为（10＋5×该组钻头数量）mB，再乘加工插件的并行数。
未装治愈插件时，每种流体平均产速上限80 mB/秒。
治愈Tier 1–6依次提高到160、320、640、1,280、2,560 mB/秒和无限制。
每种流体独立计时，超过上限时延长该组等待间隔，整批产物不会被截断。

## 升级
加速卡最多4张，陨石超频卡最多4张，工业先锋的速度，效率，加工插件各一张，接受Tier 3–6。
每种类型只能占一个槽。第六槽专放一张治愈插件，接受Tier 1–6。

基础配方完成时间为160 tick，每张加速卡减少10 tick、每张超频卡20 tick，再乘速度Tier 3–6的80%/70%/60%/50%与效率的70%/60%/50%/40%，加工Tier 3–6提供总并行4/5/6/7
满加速配置为 8 tick，实际流体产速仍受治愈插件限制。

## 供能与输出

储能256,000 AE，六面支持ME及FE输入，优先使用网络盘里的FE。
